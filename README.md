# 🥗 Alimentação Saudável

Projeto de um site desenvolvido com **HTML e CSS** com o objetivo de apresentar informações sobre alimentação saudável e incentivar bons hábitos alimentares.

## 📌 Sobre o Projeto

O site apresenta informações de forma simples e organizada sobre:

- 🍎 Alimentos saudáveis
- 🥦 Frutas, verduras e legumes
- 💧 Importância da água
- 💡 Dicas de alimentação
- ❤️ Benefícios de uma alimentação equilibrada
- 📩 Formulário de contato

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3

## 📁 Estrutura do Projeto

```text
site-alimentacao/
│
├── index.html
├── contato.html
├── estilo.css
└── README.md
````

## 🏠 Página Inicial

A página `index.html` apresenta:

* Cabeçalho do site
* Menu de navegação
* Introdução sobre alimentação saudável
* Alimentos saudáveis
* Dicas de alimentação
* Benefícios
* Rodapé

## 📩 Página de Contato

A página `contato.html` possui:

* Formulário de contato
* Nome
* E-mail
* Assunto
* Mensagem
* Informações de contato

## 🎨 Design

O projeto utiliza:

* Cores verdes relacionadas à natureza e alimentação saudável
* Cards para organizar as informações
* Menu de navegação
* Layout responsivo
* Formulário estilizado
* Efeitos ao passar o mouse nos botões e links

## 🚀 Como Executar

1. Baixe ou clone este projeto.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Navegue pelo menu para acessar as páginas.

## 📚 Objetivo Educacional

Este projeto foi desenvolvido para praticar conceitos básicos de:

* Estrutura HTML
* Tags semânticas
* Links entre páginas
* Formulários
* Listas
* Estilização com CSS
* Organização de arquivos
